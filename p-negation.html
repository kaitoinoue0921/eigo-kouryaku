否定

否定は、見落とすと意味が正反対になる。「どこまでが否定されているか」と「隠れた否定」を見抜く。

基本の否定

必須

全否定と部分否定

着眼点not と all / every / always / both / necessarily が一緒に出ている。
全否定（まったく〜ない）部分否定（すべてが〜とは限らない）
none / nothing / no one / never / neithernot all / not every / not always / not both / not necessarily / not completely

Not all students like math.

すべての学生が数学を好きなわけではない。

Difficult words are not always important.

難しい単語がいつも重要とは限らない。

ポイント：not ＋ 全部を表す語 ＝ 部分否定（「〜でないものもある」）。全否定は、none / never / neither を使う。

必須

not A but B / not only A but also B

着眼点A と B は、同じ形。強調したいのは B。

The goal is not to memorize rules but to use them.

目標はルールを暗記することではなく、それを使うことだ。

She is not only smart but also kind.

彼女は賢いだけでなく、親切でもある。

ポイント：not A but B ＝ AではなくB。not only A but also B ＝ AだけでなくBも（Bに重み）。

必須

準否定（hardly / scarcely / rarely / seldom / few / little）

着眼点形は肯定でも、意味が「ほとんど〜ない」「めったに〜ない」。

There was hardly anyone in the room.

部屋にはほとんどだれもいなかった。

I have few friends here.

ここには友だちがほとんどいない。

I have a few friends here.

ここには友だちが少しはいる。

ポイント：hardly / scarcely ＝ 程度（ほとんど〜ない）、rarely / seldom ＝ 頻度（めったに〜ない）、few ＝ 数、little ＝ 量がほとんどない（否定的）。a few / a little ＝ 少しある（肯定的）。only a few ＝ ほとんどない、quite a few ＝ かなり多い。

注意：hardly / scarcely と not は併用しない（× not hardly）。

必須

no ＋名詞（1つも〜ない）

着眼点名詞の前の no は、not any の意味。

I have no time.

私には時間がまったくない。

No student came to the party.

パーティーに来た学生は1人もいなかった。

He is no fool.

彼は決して愚か者ではない。

ポイント：no ＋ 名詞 ＝ 少しも〜ない。主語にあれば「〜する人は誰も…ない」。be no ＋ 名詞は、強い否定（決して〜ではない）。

差がつく

no longer / not ... any longer / no more

着眼点もはや〜ないを表す表現。

He no longer lives here.

彼はもうここには住んでいない。

I can't wait any longer.

私はこれ以上待てない。

ポイント：no longer ＝ not ... any longer ＝ もはや〜ない（時間）。no more は、程度や数量の「もう〜ない」にも使う。

差がつく

強い否定の副詞句（not at all / not in the least など）

着眼点少しも〜ないを表す表現。

I'm not in the least tired.

私は少しも疲れていない。

There was not a single mistake.

間違いは1つもなかった。

ポイント：not at all / not a bit / not in the least / not a single 〜 ＝ 少しも〜ない。

見落としやすい否定

差がつく

二重否定（否定＋否定＝強い肯定）

着眼点否定語が2つ出ている。

I never see this picture without thinking of my mother.

この絵を見ると、必ず母を思い出す。

There is no rule without exceptions.

例外のない規則はない。

It is not impossible.

不可能ではない。（可能かもしれない）

ポイント：never ... without -ing ＝ 〜すると必ず…する、no ... without ~ ＝ 〜のない…はない。否定を2回打ち消して、肯定に読み替える。

差がつく

否定を含む慣用表現

着眼点形と意味がずれているので、まとめて覚える。
表現意味
nothing but 〜〜だけ（＝ only）
anything but 〜決して〜ではない
all but 〜ほとんど〜（＝ almost）
far from 〜決して〜ではない
free from / free of 〜〜がない
by no means 〜決して〜ない
none other than 〜他ならぬ〜
cannot ... too 〜いくら〜してもしすぎない

He is anything but a fool.

彼は決して愚か者ではない。

The work is far from finished.

その仕事は少しも終わっていない。

You cannot be too careful.

いくら注意してもしすぎることはない。

注意：nothing but（〜だけ） と anything but（決して〜ない） は、逆の方向。

差がつく

否定の意味を含む語（fail / refuse / beyond など）

着眼点not がなくても、意味が否定になる語句。
語句意味
fail to do〜しない・〜できない
refuse / deny拒否する・否定する
lack / absent欠けている・いない
too ... to do〜すぎて…できない
beyond 〜〜の及ばない：beyond my understanding（理解できない）
above 〜〜しないような：above telling lies（嘘をつくようなことはしない）
but for 〜 / without 〜〜がなければ

The idea is beyond my understanding.

その考えは、私には理解できない。

ポイント：肯定文の形でも、意味は否定。訳すときに否定の形に直す。

差がつく

否定の転移（I don't think ~）

着眼点think / believe / suppose / expect ＋ that 節の否定。

I don't think he is honest.

彼は正直ではないと思う。

ポイント：日本語の直訳（思わない）ではなく、「〜でないと思う」と、that 節の中を否定して訳す。not は that 節の内容を否定している。

差がつく

否定の範囲（not ... because 〜）

着眼点not がどこまでを否定しているか。

I did not leave because I was angry.

怒ったから出たのではない。（理由を否定）

He did not come, because he was ill.

彼は病気だったので、来なかった。（コンマで区切ると、理由を述べる）

ポイント：not ... because 〜 は、「〜だから…したのではない」（理由の否定）と、「〜だから…しなかった」の両方に読める。コンマ・文脈・後ろの but で決める。

差がつく

否定副詞句が文頭に出る倒置（on no account / by no means など）

着眼点文頭の at no time / on no account / under no circumstances / in no way。

On no account should you open this door.

決してこのドアを開けてはならない。

Under no circumstances will I agree.

どんな場合でも、私は同意しない。

ポイント：否定語句が文頭に出ると、倒置（助動詞 ＋ S ＋ V）になる。「決して〜ない」と強く訳す。

ここまで不要

否定疑問文・付加疑問文

着眼点Don't you 〜? や、文末の ..., don't you?。

線引き：読解の得点には直結しにくい。否定疑問文は「〜ではないのですか」、答え方が日本語と逆になる（yes/no は、答えの内容が肯定か否定かで決まる）と知っていれば十分。

確認問題

クリックすると答えが開く。答えを見る前に、頭の中で答えを決めてから開く。

次の文を訳しなさい。
Not all students like math.

すべての学生が数学を好きなわけではない。

not ＋ all は部分否定。

次の文の意味を答えなさい。
He is anything but a fool.

彼は決して愚か者ではない。

anything but ＝ 決して〜ではない。nothing but（〜だけ）と混同しない。

次の文を訳しなさい。
I never see this picture without thinking of my mother.

この絵を見ると、いつも母を思い出す。

never ... without -ing ＝ 〜すると必ず…する（二重否定）。

few と a few の違いを、例文で答えなさい。
I have few friends. ／ I have a few friends.

前者：友だちがほとんどいない ／ 後者：友だちが少しはいる

a がつくと肯定的（少しある）、つかないと否定的（ほとんどない）。
