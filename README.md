# 受験英語 完全攻略ノート（仮称）

長文を解く前に「記号・文法・構文・論理」のルールを全部わかっておき、同時に「ここまでは不要」の線引きも示す静的Webサイト。
対象は共通テスト〜MARCH・地方国公立。収益化は当面なし（無料公開）。

## 構成（公開物はHTML/CSS/JSのみ。ビルドは手元でPython）
- `index.html` トップ（3段階の線引き・学ぶ順・使い方）
- `symbols.html` 記号の役割（手書きHTML）
- `grammar.html` 文法リファレンス（手書きHTML）
- `patterns.html` 構文ライブラリの入口（**自動生成**）
- `p-order / p-modifier / p-clause / p-verbal / p-compare / p-negation / p-subjunctive / p-verbs .html` 構文8分野・130項目（**自動生成**。元データは `tools/content/*.py`）
- `before-reading.html` 長文の前に（手書きHTML）
- `score-tips.html` 得点のコツ（手書きHTML）
- `skip-list.html` ここまでは不要（手書き＋構文の不要項目を自動集計）
- `toc.html` 全体の目次（**自動生成**。全項目へのリンクと、ページ別の完了数）
- `progress.html` 記録（レベル・経験値・トロフィー・連続日数）
- `privacy.html` プライバシーポリシー
- `assets/style.css` `assets/app.js` 共通、`assets/manifest.js` 項目一覧（自動生成）、`assets/search-index.js` 検索インデックス（自動生成。初めて検索を開いたときに読み込む）

## ビルド（項目を追加・変更したら必ず実行）
```
python3 tools/build_all.py
```
構文ページの生成、ナビの統一、不要リストの構文分の集計、`manifest.js`（レベル・トロフィー用の全項目一覧）の生成を行う。
構文の項目を足すときは `tools/content/<分野>.py` に `i(...)` を1つ足す（`id` はサイト全体で重複させない）。
手書きページ（symbols / grammar / before-reading / score-tips）に項目を足したときも、`build_all.py` を実行して `manifest.js` を更新する。

## 検索・目次（app.js）
- ヘッダーの「検索」ボタン（または `/` キー）で、全項目を横断検索。スペース区切りはAND検索。結果から、隠れている項目（完了済み・「不要」）にも移動できる（一時的に表示して強調する）
- 各ページの先頭に、そのページの目次（完了した項目には取り消し線と ✓）。全体の目次は `toc.html`

## ゲーム要素（app.js）
- 「理解した」でチェックした項目は自動で隠れる（ボタンで表示に戻せる。チェック直後は6秒間「元に戻す」が出る）
- 経験値：必須10・差がつく20・不要5・確認問題を初めて開く5。レベルは全項目の「必須＋差がつく＋確認問題」の合計に対する割合で決まる（項目が増えても難しさは変わらない）
- トロフィーは `app.js` の `TROPHIES` に定義。記録は localStorage（キーは `eiko:` で始まる）

## 項目の書き方
`<article class="item" data-tier="must|core|skip" id="...">` を1項目とする。
- `must`=必須 / `core`=差がつく / `skip`=ここまで不要
- 「理解した」チェックの `data-id` はサイト全体で重複させない（localStorage のキーになる）
- 通し番号(No.)はJSが各ページ内で自動付与する。項目の順序を変えると番号も変わる
- 図解は `.parse` 内で `.S`(主語) `.V`(動詞) `.O`/`.C`(目的語・補語) `.M`(修飾) `.cl`(節の括弧) を使う

## 制作方針
- 定評ある英文解釈・構文・文法・長文の参考書に共通する「考え方」（技術を番号で整理／着眼点→図解→訳／前から読む／用法を表で／確認問題／設問別の手順）を取り入れる。
- **例文と文章はすべて独自に書く。既存の参考書の本文・例文・解説文は転載しない。**
- 「不要」の線引きは、共通テスト〜MARCH・地方国公立の一般的な傾向にもとづく目安。志望校の過去問3年分で2回以上出た項目は「必要」に格上げする。
- 特定の生徒名・個人情報は載せない。
