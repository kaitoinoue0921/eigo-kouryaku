長文の前に

長文でつまずく原因の多くは、単語ではなく「構造」と「論理」の見落とし。演習に入る前に、ここを一通り頭に入れておく。

A. 文の骨組みを取る

すべての文は、動詞 → 主語 → 修飾を外す の順で取る。これが全部の土台。

必須

骨組みの取り方（動詞→主語→修飾を外す）

  1. 動詞を探す。動詞は見つけやすい（前置詞句や節の中の動詞は後回し）。
  2. その動詞の主語を探す。主語が長いときは、動詞から逆にさかのぼる。
  3. 修飾（前置詞句 ( )、節 [ ]）を外す。残ったものが骨組み。
  4. 骨組みが取れてから、修飾を戻して訳す。

[The idea (that sleep improves memory)] has been supported (by many studies).

睡眠が記憶を高めるという考えは、多くの研究に裏づけられてきた。

ポイント：主語が長いとき（節や that 節を含むとき）は、動詞の直前までが主語のかたまり。動詞から前に戻って、かたまりの始まりを探す。

差がつく

前から読む（意味の切れ目に / を入れる）

着眼点英文は、後ろから戻らずに、前から順に意味をとれる。

英文は意味のかたまりごとに / を入れ、前から順に理解していく。返り読み（後ろから前に戻る読み方）を減らすと、速く読めて、内容も頭に残る。

Many students / believe / that reading a passage twice / takes too much time, / but / it often saves time / in the end.

多くの学生は／信じている／文章を2回読むのは／時間がかかりすぎると／しかし／それはむしろ時間の節約になる／結局は

使い分け：読むときは前から（内容をつかむ）、訳すときは日本語として自然に整える（答案）。両方できるようにしておく。

線引き：全文をきれいに訳しながら読まなくてよい。設問に関わる箇所だけ、精読（正確な和訳）に切り替える。

必須

形式主語 It … that / to ~

主語が長くなるのを避けるため、it を仮の主語に置いて、本当の主語（that 節・to 不定詞）を後ろに回す形。

It is important to check your answers.

答えを見直すことが重要だ。

It has been shown that sleep improves memory.

睡眠が記憶を高めることが示されている。

見抜き方：文頭の It の後に is / has been + 形容詞・過去分詞が続き、後ろに that 節・to ~ があれば形式主語。訳は「〜ということは…だ」と、後ろから訳す。

必須

強調構文 It is A that ~

「〜なのは A だ」と A を強調する形。形式主語と見た目が同じなので、区別が必要。

It was the teacher that solved the problem.

その問題を解いたのは、先生だった。

見抜き方：It is 〜 that を外して、文が完全に成立するなら強調構文（The teacher solved the problem. が成立）。形式主語だと、外したときに文が壊れる。

ここまで不要

5文型の厳密な分類

SVOC などの文型は、「動詞の後ろに何が来るか」を予測するための道具。

線引き：文型の名前を答える練習や、境界例の分類（第3文型か第4文型か迷うもの）に時間を使わなくてよい。骨組みが取れて、訳せれば十分。

B. 節を見抜く

節 = S＋V を含むかたまり。1文に節が複数あるとき、「どこからどこまでが1つの節か」を見つけるのが構造把握の中心。

必須

節は3種類（名詞節・形容詞節・副詞節）

種類はたらき導く語訳の例
名詞節S・O・C になるthat, whether, if, what, how, when, where, why〜ということ／〜かどうか
形容詞節名詞を後ろから修飾（関係詞節）who, which, that, whose, when, where〜する（名詞）
副詞節時・理由・条件・譲歩を表すwhen, because, if, although, while〜のとき／〜なので

見抜き方：その節を「これ」に置き換えられれば名詞節。直前の名詞を説明していれば形容詞節。ほかはたいてい副詞節。

必須

that の見分け方

種類後ろの形例
指示代名詞（あの・それ）名詞が1つ続く／単独I bought that book.
関係代名詞主語か目的語が欠けているthe book that [I read __]
接続詞（名詞節）S＋V が完全にそろう／動詞や文頭の後ろI think that [he is right].
同格の that完全な文。前に fact, idea, news, belief などthe fact that [he left]
副詞節（so that など）so that / such … thatHe spoke slowly so that we could follow.

見抜き方の順番：①後ろが完全か欠けているかを見る → 欠けていれば関係代名詞。②完全なら、前に何があるかを見る（動詞なら名詞節、fact などの名詞なら同格）。③文頭の That S V は「〜ということは」と主語になる名詞節。

必須

what / how / when などが作る名詞節

what S V ＝「Sが〜すること・もの」。how S V ＝「どのように…するか」。動詞の目的語や主語、前置詞の目的語になる。

How a person writes reflects what he himself is.

人がどう書くかは、その人自身がどんな人かを映し出す。

見抜き方：疑問詞の後ろがS＋V の順（疑問文の語順ではない）なら、間接疑問＝名詞節。節全体を「かたまり」として、S・O・C のどれかを決める。

必須

関係詞の省略

目的格の関係詞は省略できる。名詞の後ろに S＋V がいきなり続いたら、関係詞が省略されている。

the book (that) I read yesterday

私が昨日読んだ本

見抜き方：「名詞＋名詞＋動詞」のように名詞が2つ続いたら、間に関係詞を補って読む。

差がつく

接続詞と前置詞の区別

after / before / until / since / as などは、接続詞にも前置詞にもなる。

We waited until the rain stopped. ／ We waited until late at night.

私たちは雨が止むまで待った。／ 私たちは夜遅くまで待った。

見抜き方：後ろが S＋V なら接続詞（節）、名詞だけなら前置詞（句）。節なら、その中に必ず主語と動詞がある。

C. 見落としやすい仕組み

差がつく

省略（副詞節内の S be の省略）

時・条件・譲歩の副詞節では、主語が主節と同じとき、S＋be が省略されることがある。

While (I was) walking home, I met an old friend.

家に歩いて帰る途中、旧友に会った。

見抜き方：when / while / if / though の後ろに、動詞の ing 形や過去分詞、形容詞が直接来たら、S be の省略を疑う。if necessary / if possible / when needed のように、it is が省略された形もある。

差がつく

倒置（否定語・Only が文頭）

Never / Little / Hardly / Not only / Only + 副詞（句・節）が文頭に来ると、後ろが疑問文の語順になる。

Only then did I understand the rule.

そのときになって初めて、私はそのルールを理解した。

見抜き方：文頭の否定語のあとに、助動詞や be が先に来たら倒置。「Only ＋ 副詞」は「〜して初めて」と訳すとよい。

差がつく

仮定法（現実と違うことを言う）

If S 過去形, S would ~ は「今の事実と違う仮定」。If S had p.p., S would have p.p. は「過去の事実と違う仮定」。

If I had more time, I would read the passage twice.

もっと時間があれば、その文章を2回読むのだが。

見抜き方：動詞が過去形なのに、意味が今のことなら仮定法。If が消えてWere / Had が文頭に出る倒置もある。

ここまで不要

仮定法の書き換え問題の細かい暗記

「If を使わない仮定（without / but for / otherwise など）」を、別の形に書き換える練習の細部や、If 節と主節の時制が食い違う複雑な形。

線引き：長文を読むうえでは、基本の2パターンと、without / but for / otherwise の意味が読めれば足りる。書き換えの暗記は後回し。混合型や、条件が隠れた仮定法は、構文ライブラリで確認する。

必須

無生物主語（副詞的に訳す）

人ではないものが主語になる文は、直訳すると不自然になる。主語を「原因・手段」として副詞的に訳し、目的語（人）を主語にして訳す。

Ten minutes' drive brought us to the lake.

（直訳）10分のドライブが私たちを湖に連れていった。→（自然）10分ドライブすると、湖に着いた。

見抜き方：make, enable, allow, prevent, bring, show などの動詞に注目。「〜のおかげで」「〜によって」「〜すると」と訳す。

D. 論理を読む

構造が取れたら、次は「話の流れ」。論理を示す語が、話の向きを教えてくれる。

必須

論理を示す語（ディスコースマーカー）

はたらき語読み方
逆接but, however, yet, still, nevertheless, on the contrary後ろが筆者の主張になりやすい
順接・結論therefore, thus, so, as a result, in short, in conclusion前の内容のまとめ・結果
言い換えthat is, in other words, namely, i.e.前の内容を別の言葉で
例示for example, for instance, such as例。要点をつかんでから、軽く読む
追加moreover, in addition, furthermore, besides同じ向きの情報を足す
対比on the other hand, in contrast, by contrast, while, whereas前後で内容が逆
譲歩although, though, of course, admittedly, it is true that「たしかに〜だが」。逆接とセット

読み方：マーカーに○をつけながら読むと、話の向きが変わる場所が見える。設問の答えは、逆接・結論・言い換えの周辺にあることが多い。

必須

指示語（this / that / it / such）が指すもの

  • this / these ＋ 名詞：直前の内容を名詞でまとめ直したもの（this trend、this fact）。
  • it / they：直前の名詞。ただし形式主語の it は後ろの that 節・to ~ を指す。
  • such ＋ 名詞：「そのような」。前の内容と同種のもの。

探し方：直前の1〜2文を見る。指す内容を入れて意味が通るかを確かめる。設問では、指す内容を日本語で具体的に書く。

差がつく

パラグラフの型

  • 譲歩→逆接→主張：Some people think A. However, B. → 筆者の主張は B。
  • 抽象→具体：主張を先に言い、あとで例で説明する。
  • 問題提起→解決：疑問文（?）で始まり、次の文が答え。

読み方：各段落の最初の1〜2文と、最後の文に要点が出やすい。具体例は要点の裏づけなので、時間がないときは軽く読む（設問で例が問われることもある）。

E. 単語との付き合い方

差がつく

知らない単語は「品詞」と「文脈」で予想する

  1. その語の品詞を、文中の位置から決める（主語なら名詞、be の後なら形容詞など）。
  2. プラス・マイナスのどちらの意味かを、前後の逆接・順接から決める。
  3. 意味が予想できたら、そのまま読み進める。

線引き：全部の単語を訳せなくても、骨組みが取れれば得点できる。「不要リスト」の単語の項目も参照。

ここまで不要

注がついた難単語を覚える

本文の下に「（注）」として意味が載っている語は、出題側が「知らなくてよい」と判断した語。

線引き：注の語は覚えなくてよい。意味は注で確認して、そのまま読み進める。

確認問題

クリックすると答えが開く。答えを見る前に、頭の中で答えを決めてから開く。

次の文の主語・動詞・補語を答えなさい。
The reason why many students fail to finish the passage is that they read every word carefully.

S：The reason why many students fail to finish the passage ／ V：is ／ C：that they read every word carefully

動詞 is の直前までが主語のかたまり。訳：多くの学生が文章を最後まで読めない理由は、1語ずつ丁寧に読んでしまうことだ。

2つの that は、それぞれ何か。
I know that he is honest. ／ This is the book that I bought.

前者：接続詞（名詞節） ／ 後者：関係代名詞

前者は that の後ろが完全（he is honest）。後者は bought の目的語が欠けている。

次の英文のあとに続く内容は、どちらの向きになるか。
Many people think it is easy to learn English. However, …

「英語の学習は簡単だ」という考えに反する内容（筆者の主張）

However（逆接）以降が筆者の主張になりやすい。

It is difficult to answer this question quickly. の真主語を答えなさい。

to answer this question quickly

形式主語 It の中身は to 不定詞。訳：この質問にすばやく答えるのは難しい。

ここまで理解できたら、長文の演習に入る準備ができています。演習で詰まったら、この表に戻って「どの項目が原因か」を探してください。
